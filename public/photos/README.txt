Put your photos in THIS folder.

1. Copy your image files here, e.g.:
     public/photos/photo1.jpg
     public/photos/photo2.jpg
     public/photos/photo3.jpg

2. Then open  src/photos.js  and list each one, e.g.:
     { src: '/aeshu_birthday/photos/photo1.jpg', caption: 'The day we met 💛' }

Notes:
- Paths in src/photos.js must start with  /aeshu_birthday/photos/
- Supported formats: .jpg  .png  .webp
- If an image is missing, the site shows a soft rose placeholder instead.

(This README.txt is just a note — you can delete it once you've added photos.)
